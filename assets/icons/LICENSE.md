Only the icons the app actually uses are vendored, rather than the whole
set. Each SVG uses `stroke="currentColor"`, so icons tint to the active
accent colour at runtime instead of needing one copy per colour.

Icons supplement labels; they never replace them. Status is always conveyed
by symbol AND word, never by icon or colour alone.
